# 바다앞에 (Badaape) 웹 서비스

> **오늘 갈 수 있는 바다를 한눈에**  
> 전국 해수욕장과 스노클링 장소의 운영 상태, 해양 환경, 안전 정보, 편의시설, 최신 현장 정보를 통합해 사용자가 자신과 동행자에게 적합한 장소를 결정하도록 돕는 5개 메뉴 기반 반응형 웹 서비스입니다.

---

## 1. 프로젝트 개요
- **서비스명**: 바다앞에
- **슬로건**: 오늘 갈 수 있는 바다를 한눈에
- **기술 스택**: HTML5, CSS3 (Vanilla CSS), Vanilla JavaScript (No Frameworks, No Build Tools)
- **주요 메뉴**: `홈(index.html)` / `지도(map.html)` / `저장·비교(saved.html)` / `현장(field.html)` / `MY(my.html)`
- **데이터 관리**: `data.js` (8대 샘플 해변 및 제보 데이터) + `localStorage` (저장 장소, 비교 목록, 선호 조건, 알림, 사용자 제보)

---

## 2. 파일 구조
```text
badaape-web/
├── index.html   # 홈: 검색, 복수 필터, 추천 장소 카드, 대안 장소 추천
├── map.html     # 지도: 대화형 데모 지도 마커, 실시간 상세 패널, URL 쿼리 연동
├── saved.html   # 저장·비교: 저장 목록, 3개 장소 비교표, 자동 추천 점수 계산
├── field.html   # 현장: CCTV 시뮬레이션, 공식 통제 공고, 실시간 방문자 제보 등록
├── my.html      # MY: 프로필 통계, 선호 조건 설정, 알림 토글, 전체 데이터 초기화
├── styles.css   # BEM 기반 반응형 공통 스타일시트 (상단 네비 + 모바일 하단 독 네비)
├── data.js      # 샘플 장소 및 제보 원천 데이터셋
├── app.js       # 공통 스토리지, 라우팅, 카드 렌더러, 이벤트 핸들러
└── README.md    # 프로젝트 안내서
```

---

## 3. 실행 방법
별도의 빌드 도구나 Node.js 환경이 필요하지 않습니다.
1. 프로젝트 폴더를 엽니다.
2. `index.html` 파일을 크롬, 엣지, 사파리 등의 웹 브라우저에서 실행합니다.
3. 상단(PC) 또는 하단(모바일)의 5개 메뉴를 클릭하여 자유롭게 화면 간 이동할 수 있습니다.

## 4. 핵심 기능 안내
1. **홈 (`index.html`)**
   - **실시간 검색**: 장소명(구조라, 판포 등) 또는 지역명(거제, 제주, 강원 등) 입력 시 즉시 필터링
   - **다중 빠른 필터**: 초보자 추천, 입수 가능, 안전요원, 주차, 샤워장, 장비 대여, CCTV 다중 토글 및 초기화
   - **카드 액션**: 즐겨찾기 저장(`★`), 비교 추가(`+ 비교`), 현장 보기 즉시 이동
   - **플랜B 대안 장소**: 파도가 잔잔하고 입수 가능한 안전 대안 장소 별도 제안
2. **지도 (`map.html`)**
   - **인터랙티브 데모 지도**: 대한민국 연안 좌표 기반 마커 배치 및 입수 상태별 핀 색상 차별화
   - **URL 쿼리 연동**: `map.html?place=gujora` 형태로 접근 시 해당 장소 자동 활성화
   - **상세 패널 연동**: 마커 또는 하단 리스트 클릭 시 상세 해양 스펙과 액션 버튼 동적 렌더링
3. **저장·비교 (`saved.html`)**
   - **3개 장소 비교 매트릭스**: 초과 추가 시 토스트 안내, 비교 항목별 테이블 대조
   - **스마트 추천 알고리즘**: 입수 가능 여부, 초보자 난이도, 안전요원, 편의시설 가중치 점수를 합산해 1위 장소와 근거 추천
4. **현장 (`field.html`)**
   - **CCTV 상태 플레이스홀더**: LIVE, 최근 이미지, 연결 지연, 이용 불가 상태 시뮬레이션
   - **방문자 제보 등록**: XSS 방지 처리(`textContent`)를 적용하여 실시간 현장 상황 등록 및 `localStorage` 저장
5. **MY (`my.html`)**
   - **선호 조건 & 알림 토글**: 체크박스 변경 시 즉시 저장되며 새로고침 후에도 영구 유지
   - **전체 데이터 초기화**: `confirm()` 대화상자를 거쳐 저장 데이터 일괄 삭제 및 화면 즉각 갱신

---

## 5. 품질 및 접근성 준수
- **HTML5 시맨틱 마크업**: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer` 적용
- **웹 접근성(A11y)**: 본문 건너뛰기 링크, `:focus-visible` 포커스 링, `aria-pressed`, `aria-live="polite"` 토스트 알림
- **보안 원칙**: 사용자 입력값 렌더링 시 안전한 DOM API(`textContent`) 사용으로 악성 스크립트 방지
- **반응형 디자인**: 375px 모바일 하단 독(Dock) 네비게이션부터 1440px 데스크톱 대시보드 뷰까지 완벽 대응
